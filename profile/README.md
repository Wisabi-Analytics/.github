## Engineering Principles
We treat LLM systems like data infrastructure, not chatbots.

Every system we publish follows:

1. **Grounding before generation** – retrieval and validation precede synthesis  
2. **Deterministic where possible** – rules > models > humans fallback  
3. **Observable behaviour** – failures measured, not guessed  
4. **Economic viability** – cost per decision matters
